# Built-in MusicXML samples

These six generated MusicXML strings are the browser samples formerly used by
the combined Web App. During the split they are copied here so sample delivery
and single-file embedding are owned by `miku-score-web`.

The source files originate from the matching generated `sampleXml*.ts` assets
in `../miku-score`. Keep the sample set and this note aligned when refreshing
the Web App's bundled samples.
